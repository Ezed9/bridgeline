# Code of Conduct

bridgeline follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and critique work rather than people. Rigorous
disagreement about the security claim is welcome and expected; hostility is not.

To report conduct that violates it, contact the maintainer privately through
[GitHub](https://github.com/Ezed9). Reports are handled confidentially.
